# GIBRAT - Образовательная платформа

Полнофункциональная система дистанционного обучения с AI-наставником и интерактивными тестами.

## Возможности

- 👤 **Аутентификация**: Регистрация и вход пользователя
- 📚 **Курсы**: Доступные образовательные курсы
- 📝 **Тесты**: Интерактивные тесты по физике (Механика, Термодинамика, Электричество, Оптика)
- 🤖 **AI Наставник**: Виртуальный профессор с голосовым синтезом
- 💬 **Чат**: Общение с наставником
- 📊 **Рейтинг**: Таблица лучших студентов

## Технологии

- HTML5, CSS3, Vanilla JavaScript
- Web Speech API для TTS/STT
- DeepSeek API для AI ответов
- localStorage для хранения данных
- GitHub Pages для хостинга

## Функциональность

### Регистрация и вход
- Валидация email и пароля
- Хранение данных в localStorage
- Автоматическое перенаправление на главную после входа

### Профиль
- Отображение информации пользователя
- Виртуальный AI-наставник
- Дата регистрации

### Уроки и тесты
- 4 физических мини-теста
- Модальное окно с вопросами и ответами
- Интуитивный интерфейс

### Рейтинг
- Топ студентов
- Система баллов
- Пользовательский рейтинг
